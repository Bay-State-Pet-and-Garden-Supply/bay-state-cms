## Ownership, real-data provenance, and population

The sole operator owns construction, source review, blinded re-review, adjudication, and release decision. No external reviewer/personnel dependency is assumed; independent subagent source-packet checking may be used as an additional check, not a second human sign-off.

Use genuine POS/register/supplier XLS/XLSX/CSV exports. Preserve originals privately with provenance and SHA-256; derive the evaluated upload with only UPC, Register Name, Price, unchanged source values. Pin approved catalog checkout by Git commit. For every identity, variant, packaging, safety, rights and family judgment, retain attributable manufacturer/distributor/package/permission evidence, collection date, exact locator and raw artifact hash. Fixture corpora are not real-import provenance. Do not reuse exposed cases as holdout. Proposed construction is 600 distinct SKUs, 12 primary strata of 50 each (controls; unknown brand; unavailable profile; unavailable source; abbreviated name; near-neighbor model/flavor; unit/case; no-fit; ambiguous variant; missing safety; missing rights; actual catalog join), approximately 300 development/300 holdout; all counts are **proposal-pending-fit**, not a measured sufficiency claim. Keep every original row/disposition. Separate connected family/duplicate/canonical-source/near-duplicate components; assign once with recorded seed and balancing, previously exposed components development-only. Holdout means file-level private sealed payload, SHA-256 commitment, restricted permissions, access log; fitting receives no holdout labels. Breach retires holdout.

## Metrics (definitions copied from plan §6)

For every metric report both arms, absolute counts, denominator, percentage (zero denominator = N/A), paired change and support. Let N = all original imported rows; N_sku = distinct imported SKUs; H = holdout imported rows; G = source-adjudicated resolvable exact sellable items; S = rows where arm selected/confirmed a source; T_t = imported rows belonging to approved Product Type t; C = all included claim units in final projected fields; F = gold family groups, with pair sets over frozen import-plus-catalog universe.

- Row accounting: mutually exclusive terminal dispositions sum to N; report unresolved, denied, failed, invalid, skipped-existing, duplicate and missing output.
- Exact sellable-item resolution: correct exact identity **and** variant / N; additionally correct / G and correct / answered rows. Correct abstentions separate.
- Retrieval coverage: gold-compatible exact-item candidate in emitted set / G; also count / N; misses remain misses.
- Wrong-source: selected wrong identity/variant / S and / N. Wrong-authority: accepted source/facts with unauthorized role/domain/rights basis / all accepted-source decisions, plus affected rows / N.
- Rich-listing completion: independently correct complete listing / T_t per approved type; separately missing, unavailable, conflicted, stale, non-applicable and permitted-exception states.
- Unsupported and contradicted claims: each / C, plus affected listings / N; raw pre-review and final reviewed projections separately.
- False blocks: incorrectly blocked otherwise-ready rows / independently ready rows. Omissions: proposed, approved, rejected, revoked, stale, corrected; approved-invalid / approved omissions; outcomes / all omission decisions.
- Reviewer outcomes: accepted unchanged, corrected, rejected, deferred, unresolved, later invalidated / all reviewed rows; unreviewed / N.
- Operator effort: total active review/edit/resolution seconds, including unsuccessful rows / correctly reviewed listings; per-row distribution and action counts / N. Wall waiting separate. Domain/profile setup once and amortized over actual benefiting SKUs, count named.
- End-to-end latency: P50/P95 from import/start to first terminal preparation outcome over all rows; failures/timeouts included; successful-review latency separate; preregister nearest-rank percentile.
- Calls/tokens/retries: unique IDs and actual attempts including failures; totals and / N, / correctly reviewed listing. Search/fetch/browser: requests, failed requests, pages, actions, redirects, bytes, unavailable observations by arm.
- Cost: observed/billed totals where available; otherwise rate-derived estimate with pinned rate/date or unavailable. Show known subtotal and unknown-work count; unknown is not zero.
- Family group precision: exactly correct proposed groups / all proposed groups. Recall: gold groups recovered exactly / all gold groups. Pairwise quality: TP/(TP+FP) and TP/(TP+FN), with standalone/abstention reporting. Harmful merges: cross-gold-family merges / proposed groups; harmless split gold families / F, separately unsafe splits/publication loss.
- Preservation: correct existing main, member set/order, PF7, native semantics and unrelated fields / applicable operations separately. Publication/recovery: complete successful groups / attempted groups; recovered correctly / interrupted operations; false-success count.

Existing reports/validators are evidence seams, not a complete §11.1 evaluator. Deduplicate shared call IDs, allocate shared costs equally across actual beneficiaries for per-row reporting and reconcile totals. Never treat frozen replay as live latency, acquisition usage as complete billing, catalog assignment as gold, or agreement as proof. Relevant seams include original import manifest/routes, discovery capture, `evaluateItemChecklist` and review gates, `buildClaimUnits`, omission/review ledgers, repository call evidence, family validators/ShopSiteProductCodec and push receipts. Missing capture means unavailable/blocked.

## Review protocol (§7)

Operator is sole product reviewer/final adjudicator. (1) Source-only first pass records identity, variant axes, source roles, required/optional/inapplicable facts, safety/rights and family truth without predictions. (2) Independent subagent receives frozen source packet/rubric only, not outputs, fitted thresholds or first-pass answers; cites locators and uncertainty. (3) Randomized, blinded operator second pass hides first labels; rechecks identity/variant all rows and applicable claims/omissions/family outcomes. (4) Record both judgments and exact resolving evidence; no majority vote or model-confidence proof. (5) Unresolvable externally established cases remain explicitly insufficient/ambiguous; unknown support blocks required conclusions. (6) Hash source-derived gold and disagreement ledger before revealing arm identity/scores. (7) Review randomized arm order, raw outputs immutable, corrections separate. Disclose operator familiarity and learning; counterbalance order by component. This is not a two-person labor study.
